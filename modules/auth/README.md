# auth

Module crate generated by `cargo modular make:module auth`.

Web login, sign-up and sessions, plus three one-time email links (through the `mail` module).

| Route | What it does |
|---|---|
| `/login`, `/register`, `/logout` | cookie sessions; sign-up signs in an unverified account and mails a link |
| `/email/verify` | notice page for a signed-in person who is not verified (`VerifiedAuth` redirects here) |
| `/email/verify/{secret}`, `/email/verification-notification` | verify the address; ask for the link again |
| `/forgot-password`, `/reset-password/{secret}` | reset a forgotten password (signs out every device) |
| `/login/email-link`, `/login/email-link/{secret}` | sign in without a password |

Tables: `sessions`, `user_security_tokens` (SHA-256 of each link secret, `purpose`, `expires_at`, `used_at`). Command:
`auth:prune-sessions` also removes used and expired links. Details: `tutorials/14-auth-and-sessions.md`.
