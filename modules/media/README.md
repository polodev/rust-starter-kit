# media

Module crate generated by `cargo modular make:module media`.

## Where files are kept

`MEDIA_STORAGE` in `.env` chooses the storage: `local` (default, `storage/uploads`) or `r2` (the `R2_PUBLIC_BUCKET` with
`R2_ENDPOINT`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`). With `r2`, also set `MEDIA_DISK=r2-public` (written to the
`media.disk` column) and `MEDIA_PREFIX` (a folder in the bucket). `R2_PUBLIC_URL`, once the bucket has a public
address, makes public files load straight from R2. Restart after changing `.env`.

`cargo run -- task media:move-local-uploads [dry-run:true]` copies files that are still in `storage/uploads` to the
current storage and updates their rows; the local copies are kept.

All collections share the one bucket. Keep the bucket's public access off until private collections have their own
private bucket.
